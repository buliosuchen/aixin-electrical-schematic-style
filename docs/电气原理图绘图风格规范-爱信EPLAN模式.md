# 电气原理图绘图风格规范（无锡爱信 / EPLAN 模式）

> 来源样本：`8K6_8K7.pdf` —— 无锡爱信机械科技有限公司，为南通瑞翔 8K6&8K7 炉前锂盐投料项目绘制的成套电气原理图（项目编号 WAXX12819，共 167 页，EPLAN 出图）。
> 制定日期：2026-10-02。**此后所有电气原理图类绘图均按本规范执行。**

---

## 1. 总体风格

- EPLAN 风格原理图：**彩色绘制**，不是黑白线条图。
- 幅面：**A3 横向**。
- 图面分区：顶部为坐标网格（列 0–9 / 行 A–F），底部为标题栏，中间为图面区。
- 页面类型成套出现：封面 → 布局图 → 主回路/电源 → 控制回路 → 变频器 → 电机 → HMI → IO 分配 → 端子图 → 端子接线图 → BOM（部件汇总表）。

## 2. 颜色体系（铁律）

| 颜色 | 色值 | 用途 |
|---|---|---|
| 红 | `#FF0000` | 全部导线、连接线、跨页箭头线 |
| 蓝 | `#0000FF` | 设备代号（如 `-KM1`）、设备外框、线号（如 `DC24+`）、端子编号 |
| 绿 | `#008000` | 页交叉引用（如 `/10.7:D`）、坐标网格数字、接地母排虚线 |
| 品红 | `#FF00FF` | IO 模块外框（虚线）、IO 端子圆圈 |
| 黑 | `#000000` | 中文功能描述、品牌+订货号、技术参数 |
| 橙 | `#E8720C` 左右 | 布局图中 DIN 导轨 |
| 青灰 | `#2E8B8B` 左右 | 布局图中柜体 |
| 浅灰 | `#C0C0C0` 左右 | 布局图中安装板 |

- 封面页例外：黑白 + 粗黑横条 + 公司 Logo。
- 布局图例外：彩色柜体布置（柜体青灰、安装板灰、导轨橙、设备标签蓝色）。

## 3. 图框与标题栏

- 外框 + 内图面区；顶部列坐标 0–9、左右行坐标 A–F，均为绿色小字。
- 底部标题栏字段（从左到右）：
  - `Previous:` 上一页 / `Next:` 下一页（页码，绿色）
  - 日期 / 校对 / 审核
  - 项目描述（如"南通瑞翔 8K5 炉前包覆和炉后发送"）
  - 客户（如"南通瑞翔"）
  - 页描述（如"旋转阀"、"ET_DQ1"、"端子图_XWgBox100"）
  - 功能位置 `= RK6T` / 安装位置 `+ MCP`
  - 项目编号（如 `WAXX12819`）
  - 页数 `N / 36`、总页数 `167`
- 标题栏中填写项用绿色字，栏目标题用黑色字；左下角放公司小 Logo。

## 4. 字体

- 无衬线字体（中文用 Noto Sans SC / 思源黑体风格），设备代号加粗蓝色。
- 字号层级：设备代号最大 → 中文功能描述 → 规格/品牌型号最小。

## 5. 设备代号体系

设备代号一律前缀 `-`，蓝色加粗，置于设备符号上方或左侧，并配 3–4 行堆叠标注：

```
-KM1            ← 蓝色加粗
LC1D09BD        ← 规格型号（黑）
Schneider       ← 品牌 + 订货号（黑）
```

常用代号：

| 代号 | 含义 | 代号 | 含义 |
|---|---|---|---|
| `-Q` / `-QF` | 小型断路器/主断路器 | `-QM` | 电机保护断路器（GV2ME） |
| `-KM` | 交流接触器 | `-DJ` | 中间继电器（RSL1PVBU，DC24V 1CO） |
| `-F` | 熔断器 | `-DC` | 开关电源（ABL8RPS24050） |
| `-EB` | 接地汇流排/母排 | `-BP` | 变频器（FR-F840） |
| `-M` | 电机 | `-X` | 端子排（-X1, -XMT1…） |
| `-W` | 电缆（如 `-W2 YJV 4*1.5`） | `-IM` / `-CM` | 通信模块 |
| `-ET_DIx` / `-ET_DQx` / `-ET_AIx` | ET200SP IO 模块 | `-JXQ` | 集线器 |
| `-SA` / `-SB` / `-HA` | 面板开关/按钮/指示灯 | `-XK` | 称重仪表端子 |

- 继电器画法：线圈（A1/A2）与触点（11/14）分开画在不同位置，触点旁用绿色标注线圈所在页（如 `/10.7:D`）。
- 电机符号：圆圈内 `M` + `3~`，下方标注 `-M4`、`380V 0.55KW 1.5A 3~`、功能名、PE 接地端。
- 断路器符号旁标注极数/脱扣（如 `3P/D10`、`4-6.3A`）。

## 6. 交叉引用（绿色，铁律）

- 跨页信号线：红色线 + 红色箭头，标注格式 **`线号 /页.列:行`**，线号蓝色、页码绿色。
  - 例：`5.8:A / L1` → `L1 / 11.0:A`；`DC24+ / 12.0:A`；触点旁 `/10.2:C`。
- 同一信号的源头与目标必须成对出现，页码双向可查。

## 7. 线色与电缆标注

- 导线旁用蓝色标注线色 + 线径：`BK 2.5mm²`、`BU 1mm²`、`BN 2.5mm²`。
- 线色代码：BK 黑、BU 蓝、BN 棕、GY 灰、GN/YE 绿黄、RD 红、WH 白。
- 电缆标注格式：`-W2`（蓝）+ `YJV 4*1.5`（黑）+ 每芯颜色（`BK BN GY GNYE`）+ 功能名（如"转阀电机"）。
- PE 线：绿色虚线表示接地母排（`-EB1 接地母排`）。

## 8. IO 分配页模式

- 整页中央一个品红虚线大框表示 IO 模块。
- 框顶标注：订货号（`6ES7132-6BH00-0AA0`，蓝）+ 类型（`DQ 16x24 VDC BA`）+ 系列（`ET 200SP`）+ 品牌（`SIEMENS`）。
- 框内：16 个通道矩形符号，上方依次标注地址（`Q30.0`）、端子号（`1…16`）、通道号（`DQ0…DQ15`，品红圆圈），下方竖排中文功能名（黑）。
- 模块左上角蓝色代号 `-ET_DQ1`，上方绿色列出各通道信号来源页（如 `/10.7:C`）。
- 模块电源 `L+` / `M` 红色线引至底部母线，标注跨页去向。

## 9. 现场设备功能盒模式（蓝色框）

DI/DQ 点在原理图中用蓝色小框表示，框内 4–5 行：

```
-ET_DI1        ← 模块代号（蓝）
I30.0           ← 地址
缓存仓下料转阀故障  ← 中文功能（黑）
-DJ1            ← 对端设备
DI0             ← 通道
```

## 10. 端子图模式

- 表格列：功能文本 | 目标代号 | 线号 | 端子号 | 线号 | 目标代号 | 端子放置。
- 端子放置列用绿色标注来源页（如 `/11.1:D`）。
- 每张端子图表头标注端子排代号（如 `=RK6T+MCP-XWgBox100`）。

## 11. 布局图模式

- 彩色：柜体青灰、安装板浅灰、DIN 导轨橙色。
- 设备按实际比例排布在导轨上，设备代号蓝色标在设备上方。
- 大设备（变频器 `-BP1`、集线器 `-JXQ1`）单独画外形框。
- 底部端子排画出全部端子并标注编号。

## 12. BOM（部件汇总表）模式

- 表格列：序号 | 产品组 | 部件编号 | 铭牌文本 | 技术参数 | 品牌 | 数量。
- 部件编号蓝色（如 `A9F19310`、`6ES7131-6BH01-0BA0`）。

## 13. 排版习惯

- 顶部横向布置电源母线（L1/L2/L3、DC24+/DC24-），信号自上而下流动。
- 同类设备纵向对齐成列（如 -QM1/-QM2/-QM3 三列并排）。
- 一页只讲一个主题，页描述即主题名。
- 留白大、不拥挤；竖排中文用于 IO 通道功能名。
